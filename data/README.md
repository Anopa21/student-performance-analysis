## Files

- `student-por.csv`: the original file for the Portuguese-language course (649 students, 33 columns,
  values separated by semicolons). It is included here unmodified, as downloaded from UCI.
- `student-por-clean.csv`: **not included in the repository.** It is generated by `src/clean_data.py`,
  which adds one column (`g3_zero`, flagging students whose final grade is 0) and does not remove any rows.

To recreate the cleaned file, run `python src/clean_data.py` from the project root.
